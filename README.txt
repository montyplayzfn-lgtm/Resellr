RESELLR starter project

This is a front-end prototype, not a production marketplace-data service.
It calculates estimated profit from the values entered and saves research in
the browser on the current device. It does not connect to Vinted, Depop, eBay,
or any live sold-listing data.

NEXT:
1. Create a GitHub repository named resellr.
2. Upload all files and the icons folder from this ZIP.
3. Import the repository into Vercel and deploy.
4. Open the deployed HTTPS URL in Safari on iPhone.
5. Use Share > Add to Home Screen > turn on Open as Web App > Add.

Do not put passwords, API keys, or private customer information in this project.
For account creation and any paid services, ask a parent/guardian to help.
